An entry for the make.fun bounty **"The One-Line Laugh"** — one funny
line, under 200 characters.

## The line

> I finally cleaned my inbox to zero, and Gmail sent me a congratulations email.

## Why this line fits the judge brief

- **Surprise at the end that still makes sense.** Inbox zero feels like
  a victory, so a congratulations email is the natural reward — except
  the reward is the very thing you just escaped: another email.
- **An everyday truth people recognise.** Anyone who has fought an
  overflowing inbox knows the grind, and knows the inbox never stays
  empty for long.
- **Economy of words.** One sentence, 78 characters, no setup wasted:
  the whole joke is the punchline arriving as the last word.

## How to run

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

The program writes the line to `entry.txt` inside the directory named by
`MAKEFUN_OUTPUT_DIR` (default `/output` when unset). It uses only the
Python 3 standard library, writes no trailing newline, and is
deterministic: every run produces the same bytes.

## The gate

The bounty requires `entry.txt` to be one line of 1 to 200 characters.
This entry is 78 characters, one sentence, no trailing newline.
